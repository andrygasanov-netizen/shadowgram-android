# Ugram for Android

Неофициальный клиент Telegram для Android с расширенными функциями. Основан на официальном [Telegram for Android](https://github.com/DrKLO/Telegram) (версия 13.2.2). Версия для iPhone: [ugram](https://github.com/andrygasanov-netizen/ugram).

> Ugram не связан с Telegram FZ-LLC. Это независимый форк с открытым исходным кодом (GPL v2).

## Установка

Скачайте `Ugram.apk` со страницы [последнего релиза](https://github.com/andrygasanov-netizen/ugram-android/releases/latest) и установите его. Сборка только для arm64 (все современные телефоны).

## Возможности

Все настройки: **Настройки → Ugram Tools**.

- Режим призрака: без «прочитано», «печатает…», «в сети», скрытый просмотр историй.
- Удалённые сообщения остаются в чате с меткой 🗑; история правок сообщений.
- Одноразовые медиа сохраняются (метка 🔥) и «Пометить просмотренным».
- Блокировка чатов по отпечатку и скрытые чаты.
- Безлимитные закрепы, папки «Мои группы» и «Мои каналы», авто-принятие заявок, напоминания о непрочитанном.
- Стиль текста, авто-постфикс, эффект сердечка, авто-стикер, редактирование двойным тапом.
- ID и дата-центр в профиле, подтверждение звонка, настраиваемое меню сообщений, «Сохранить в Избранное».
- Качество отправляемых фото, большие фото, кружки на заднюю камеру, отключение автозагрузки.
- Скрытие историй, секунды во времени сообщений, без эффекта удаления и перехода к следующему каналу.
- Вход по QR-коду с другого устройства.

## Сборка

Нужны JDK 21 и Android SDK/NDK. В `local.properties` укажите свои `UGRAM_API_ID` и `UGRAM_API_HASH` с [my.telegram.org](https://my.telegram.org), затем:

```
java -classpath gradle/wrapper/gradle-wrapper.jar org.gradle.wrapper.GradleWrapperMain :TMessagesProj_App:assembleAfatRelease
```
